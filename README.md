# GTA6 陪玩手冊

PS5 繁體中文《GTA6》攻略網頁：從序章走到結局，每個任務一步一步帶你過，會暴雷的地方都先收起來，想看再點開。

**網站：** https://rlin1027.github.io/gta6-guidebook/

## 內容

- 序章到第 5 章全部主線與選擇性任務：怎麼開始、步驟、卡關提示、選擇與後果、不可逆節點提醒
- 結局與決定因素（整區折疊，重大暴雷）
- Strangers & Freaks 支線與支線活動、收集品、PS5 獎盃、作弊碼
- 遊戲內已證實的彩蛋與秘密（含 X 上玩家回報，另外標示）
- 手機優先的版面：章節列、底部導覽、全站搜尋、勾選進度（存在你的瀏覽器裡）

## 更新

每週六自動整理一次：補上攻略站與 X 上的新內容、遊戲更新檔的影響，更新後推送到這個 repo，GitHub Pages 會自動換成新版。每次更新內容會列在網頁最上方的「最近更新」。

## 檔案

- `index.html`：網頁本體
- `data.json`：全部攻略內容（網頁載入時讀取）

## 聲明

非官方攻略，與 Rockstar Games、Take-Two 無關。文字皆根據公開的攻略網站與玩家回報重新整理撰寫，每一項都附原始來源連結；遊戲畫面、地圖與圖文攻略的版權屬於各自的所有者，本站不轉載圖片，只提供連結。
